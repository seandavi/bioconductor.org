# AGENTS.md

bioconductor.org's source. On `devel` the site is built by nanoc (Ruby); the
`astro` branch moves it to Astro, tracked in
[Bioconductor/bioconductor.org#440](https://github.com/Bioconductor/bioconductor.org/issues/440).
These rules are for the `astro` branch.

## Layout

| path | what |
|---|---|
| `content/`, `etc/`, `config.yaml`, `assets/` | The site's content, in nanoc's form: a page body plus a `.yaml` sidecar, the course table, site config, and static files. The core team edits these on `devel`. |
| `pipeline/` | Python that converts that content at build time into `astro/data/`. The converter is temporary, until the freeze. |
| `astro/` | The Astro site. Pages and components in `astro/src/`. Data schemas in `astro/src/content.config.ts`. |
| `astro/data/`, `astro/public/`, `astro/dist/` | Generated by `just`. Gitignored; never edit them. |
| `layouts/`, `lib/`, `Rules`, `Rakefile`, Gemfiles | nanoc. Left alone until #436 removes them. |

## Commands

```bash
just install   # npm ci in astro/
just test      # pipeline (unittest) and renderer (node --test) tests
just build     # data snapshot + content + assets, then the full Astro build
just dev       # the same inputs, then the dev server
just parity    # after a build: everything nanoc would publish is in astro/dist
```

Python needs only PyYAML. `just data` pulls the package-data snapshot from
`https://bioconductor.org/_ci/site-data.tar.zst`, which is public.

## Rules

- **Content stays in nanoc's form until the freeze.** Convert at build time in
  `pipeline/`; don't rewrite `content/` on this branch. That keeps merges from
  `devel` conflict-free. At the freeze the converter runs once and its output
  is committed (#434, #439).
- **Fix data at its source.** A schema error in a course, event or config value
  is fixed in `etc/course_descriptions.tsv`, `content/**.yaml` or
  `config.yaml`, never in generated output and never by loosening the schema
  to fit a typo. Explain each fix in the PR.
- **Every change is a PR into `astro`** from a short branch, on
  [seandavi/bioconductor.org](https://github.com/seandavi/bioconductor.org).
  CI (`.github/workflows/astro.yml`) must pass: YAML syntax, tests, build,
  canonical/sitemap/robots checks, and internal links.
- **Issues live upstream** in Bioconductor/bioconductor.org, labeled
  `astro-migration`. A merge into `astro` can't close them, so close the issue
  by hand with a link to the PR and add the `on-astro` label.
- **Nothing publishes from this branch.** bioc-website still builds
  production until the cutover.
- **Everything here is public.** No credentials, internal hostnames, or
  people's informal remarks.
- Match the surrounding code's style. Comments say why, not what.
